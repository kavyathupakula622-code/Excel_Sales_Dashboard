# Excel_Sales_Dashboard

Project Overview

This project is an interactive Sales Dashboard created using Microsoft Excel to analyze and visualize sales performance.

The dashboard helps understand sales trends, product performance, and key business insights through charts and visual representations.

Tools Used
- Microsoft Excel 2021
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

Key Features
- Sales Performance Analysis
- Product-wise Sales Analysis
- Region-wise Sales Analysis
- Interactive Dashboard
- Visual Representation using Charts
- Data Filtering and Insights

Project Objectives
- Analyze sales data.
- Identify top-performing products.
- Understand sales trends.
- Compare business performance.
- Present insights through an interactive dashboard.

Project File
- "Sales_Dashboard.xlsx" – Complete Excel Dashboard.

Conclusion

This project helped me improve my Excel skills and understand how data analysis and visualization support business decision-making.
